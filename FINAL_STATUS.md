## 💡 How It Works

### Error Handling Flow
```
Error Occurs
    ↓
Is it a component error?
    ├─ YES → ErrorBoundary catches → Shows UI
    └─ NO ↓
Is it an API error?
    ├─ YES → try-catch → Shows toast
    └─ NO ↓
Is it a global error?
    ├─ YES → Global handler catches
    └─ NO ↓
Is it a data error?
    ├─ YES → Safe operation → Returns default
    └─ NO → Continues normally

App never crashes ✅
```
